# Product Context

## 为什么存在

官方 Kimi Code VS Code 扩展面向英文用户，且部分体验细节（用量可视、通知、提示词打磨等）不符合中文社区用户的习惯。本分支让中文用户获得开箱即用的中文界面和更贴合本地使用习惯的交互。

## 解决的问题

- 界面英文 → Webview 全面中文化（含错误提示、审批/提问文案）
- 上下文与额度不透明 → 状态栏百分比 + tokens 明细 + 5 小时窗口进度条
- 会话后台运行无感知 → 审批/提问/完成/失败系统通知（失焦进系统通知中心）
- 提示词质量依赖用户自己 → 输入框内置一键提示词优化（可选模型/思考模式、可自定义优化提示词）
- 引用文件繁琐 → 拖拽文件/文件夹（按住 Shift）直接插入 `@` 引用

## 用户与体验目标

目标用户：中文语境的 VS Code 开发者，可能同时安装官方扩展（命名空间隔离保证互不干扰）。

体验目标：

- 零配置上手：登录即用，通知默认开启、自动命名等进阶项默认关闭
- 可发现性：欢迎页含快捷键指南与功能提示（如拖拽引用说明）
- 不打扰：窗口聚焦时应用内通知，失焦才进系统通知中心
