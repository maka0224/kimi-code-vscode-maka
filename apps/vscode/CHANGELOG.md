# Changelog

## 0.3.2

- 特性：输入后续文字建议（ghost text）——打字时实时预测后续文字，灰色虚影显示在光标后，Tab 接受全部、Esc 丢弃、继续打字自动裁剪或刷新；slash/`@` 菜单打开与生成回复期间不显示。配置在输入框设置菜单（齿轮）的「输入建议」弹窗中（按工作区持久化）：启用开关（默认关闭）；建议方式——`混合`（历史会话记录前缀匹配优先，无匹配时停顿 400ms 由模型生成）/ `历史会话记录` / `大模型`；建议模型下拉选择（默认跟随当前会话模型，仅大模型/混合方式生效）。模型生成为宿主侧一次性调用（不带会话上下文，失败静默降级），强制关闭思考模式。
- 特性：输入框高度增加一半——最小高度 48px → 72px，自适应上限 140px → 210px。
- 特性：提示词优化气泡的思考模式默认改为关闭（原先未缓存偏好时跟随全局思考强度）；手动选择后仍按选择缓存。

## 0.3.1

- 缺陷：Alt+Tab 切走再切回时输入框焦点未恢复——webview iframe 的 blur 事件不一定触发导致焦点标记从未记录，改由宿主广播窗口失焦事件（`WindowBlurred`）时记录，仅当切走前焦点在输入框时才在切回后恢复聚焦。
- 特性：陌生目录信任确认（对齐 kimi-cli）——打开未加入信任目录的工作目录时，webview 顶部出现提示横幅，说明受限项（项目级 MCP 配置不加载，列出受影响的服务器）；点击「信任此目录」写入信任标记（`~/.kimi-code/workspace-trust/`），引擎实时接入项目 MCP 无需重启；「忽略」仅关闭本次横幅、不阻止使用，重开窗口后再次提示。信任按工作目录判定，切换子目录后重新检查。

## 0.3.0

- 特性：提示词优化——输入框上方新增按钮栏（提示词优化居右），点击弹出气泡选择模型与思考模式（选择自动缓存，不跟随全局切换），并可编辑优化提示词（自定义 system prompt）；点击优化将结果直接写回输入框，工具行出现回退按钮可一键还原原文；请求为宿主侧一次性调用（kosong 直连所选模型），不进会话、不写入历史。
- 特性：同步上游扩展 0.7.4/0.7.5——`@` 文件建议改由引擎实时提供（更快更准），建议列表匹配字符高亮，文件夹可作为 `@` 引用插入；图片/视频入口仅在未输入查询词时显示，移除 Browse folders 模式。
- 缺陷：修复 `@` 与 `/` 建议列表在滚动边缘鼠标停留时的抖动。
- 缺陷：引擎允许 Bash 工作目录位于工作区根之外（此前会被拒绝）。
- 缺陷：上下文压缩丢失后，再次访问目录时重新提醒未注入的 AGENTS.md。
- 特性：kimi-cli 旧数据迁移更完整（含 plans 等），迁移完成或关闭后不再重复弹出迁移提示。
- 特性（引擎内部，实验性）：回合级文件历史快照。
- 特性（内部）：webview 数据层由 ahooks 迁移至 TanStack Query，并新增 webview 单元测试。

## 0.2.3

- 修复长时间（超过 10 分钟）运行的回合被 Webview 桥接超时误判为发送失败的问题：消息被弹回输入框、生成状态被误清，而引擎其实仍在执行；`streamChat` 桥接调用不再设超时（回合完成/失败本就走 StreamEvent 事件推送，返回值无人消费，超时只会误判）。
- 修复引擎侧错误（v2 引擎 `Error2`，如 session.busy）被一律误报为「Internal error occurred.」的问题：错误码改为透传（KimiError 与 Error2 均携带字符串 code），命中对应的中文提示。

## 0.2.2

- 会话标题：首轮对话完成后自动命名会话，新增配置 `maka.autoGenerateSessionTitle`（默认关闭）——勾选时调用大模型生成标题（走 kimi-code 托管标题接口），未勾选时取首条提问的前 20 个字作为会话名称；顶部会话名称点击即可重命名，命名与重命名后的标题自动同步到通知前缀。
- 界面结构调整：顶部改为当前会话名称（点击即改，失焦/回车保存）；「会话详情」（会话 ID / 消息数）并入输入框工具行右侧上下文用量的弹出层；上下文用量与额度信息移入输入框工具行（与发送按钮组以分隔线隔开）；会话列表的重命名入口移除。
- 欢迎页快捷键指南与随机提示中加入「按住 Shift 拖入文件/文件夹插入引用」说明，提升拖拽引用功能的可发现性。
- 开发体验：开发模式下自动轮询 `dist/webview.js`，vite watch 重建后自动重载所有 webview（HTML 附带 cache-buster），改界面不再需要手动 Reload Webviews。
- 修复首轮对话后顶部会话名称不刷新的问题：标题落盘（自动命名/大模型生成/重命名）后由宿主主动推送 `sessionTitleChanged` 事件更新顶栏，不再依赖消息数变化重新拉取；同时修正未勾选大模型命名时「首条提问前 20 字」回退被引擎默认标题挡住、不生效的问题（仅手动命名的标题不覆盖）。
- 修复计划模式完成后的审阅框把整份计划原文挤在两个等宽小框里、完全不换行无法阅读的问题：计划正文改为 Markdown 渲染并默认展开，描述框只保留短提示。
- 修复新增的重命名会话桥接方法缺少参数校验、重命名时报「Invalid bridge params」失败的问题。

## 0.2.1

- README 特性列表改为按版本分组的列表（新版本在前，组内 `特性：说明` 形式）。
- 通知配置从对象形式改回 6 个扁平配置项 `maka.notifications.*`，设置界面可直接勾选并自动归入 Notifications 分组（对象形式只能在 settings.json 中编辑）。
- 通知内容前缀对话标题（缺省时退回最近一条提问），审批 / 提问 / 完成 / 失败各有独立文案，多会话并行时可区分来源。
- 对话消息头像同步替换为新 Logo（复用 `kimi-icon.svg`）。
- 修复长时间运行后发送消息直接失败、文字被弹回输入框的问题：回合开始前失败时先静默取消引擎残留状态并重试一次，仍失败才报错。
- 拖动文件或文件夹时输入框改为显示居中蒙层提示「按住 Shift 拖动后释放」，替代原来的顶部小字提示条。

## 0.2.0

- 修复会话忙碌（busy）时的冲突提示：中断事件不再误清生成状态，忙碌错误给出中文提示"当前会话正在生成回复，请等待完成后再发送"。
- 会话状态通知：审批请求、提问等待、回复完成、任务失败时发送通知；窗口失焦时发送操作系统级通知（进系统通知中心），窗口聚焦时发应用内通知（带「查看」按钮），`maka.notifications.*` 配置项可分别开关。
- 界面图标整体替换为新 Logo：活动栏图标、商店图标、左上角标识、欢迎页/登录页横幅。
- 修复思考强度下拉面板被裁剪到触发按钮宽度的问题，缓存失效提示文案正常展示。
- 每轮回复完成后在消息右下角展示本轮用时。
- 支持折叠单轮对话的中间过程：点击回复标题栏任意位置即可折叠/展开，只保留最终文本结果；回合完成后自动折叠。
- 通知配置归并为一个对象配置 `maka.notifications`（含 enabled / onlyWhenUnfocused / onApproval / onQuestion / onComplete / onError 分项），替代原先 6 个独立配置项。
- 修复运行时断连时发起新对话不回到欢迎页的问题（本地状态立即清空，不再等待可能挂起的宿主调用）。
- 修复欢迎页检测文件名笔误（`AGENT.md` → `AGENTS.md`）。
- README 增加扩展市场搜索安装说明，仓库地址更正为 [maka0224/kimi-code-vscode-maka](https://github.com/maka0224/kimi-code-vscode-maka)。

## 0.1.0

Kimi Code Maka 首个独立版本，基于官方 [kimi-code](https://github.com/MoonshotAI/kimi-code) VS Code 扩展 `0.7.3`：

- 插件 ID 改为 `kimi-code-maka`、发布者 `maka`，命令/配置/视图统一 `maka.*` 命名空间，可与官方扩展并行安装。
- Webview 界面文案全面中文化。
- 上下文用量：状态条显示百分比与进度条，点击查看输入/输出/缓存命中 tokens 与缓存命中率。
- 额度信息面板：展示账户额度用量，5 小时窗口额度带进度条。
- 支持拖拽文件/文件夹到输入框光标处插入 `@` 引用。
